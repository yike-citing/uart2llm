01 / 延续现有工作流

熟悉的 IDE，
熟悉的开发节奏。

提供标准 OpenAI 兼容 API，可接入支持自定义服务地址的 IDE、聊天客户端和开发工具。只需修改接口地址与本地 API key，就能继续使用现有模型工作流。后续计划兼容 Responses API。

01

双击运行一个轻量 Agent

Windows Agent 以单个 EXE 提供，内置页面与运行依赖。下载后双击即可使用，无需联网安装，也无需另装 Python、Node 或开发工具。

02

连接设备，设置模型服务

连接配套 ESP32，在本地管理页面完成网络和上游配置。不创建系统网络接口，不安装虚拟网卡，不修改系统路由。

03

继续使用你的 IDE 和工具

将模型服务地址设为 localhost:8765/v1，填入本地 API key。工具和习惯保留，开发无需从头适应。

02 / 完善的数据遥测与统计

连接状态、模型用量，一目了然。

数据看板

每一次调用，都有迹可循。

通过图形看板查看请求量、成功与失败、响应时间、吞吐和 Token 用量，了解模型使用情况与服务表现。

→
托盘速览

无需切换工作界面。

在系统托盘快速查看连接与模型统计，暂停或恢复服务。关闭管理页面后，Agent 继续运行。
